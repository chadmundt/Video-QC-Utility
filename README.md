🔄 Workflow: Using Video XML QC v2.3.1

The following workflow outlines how to prepare, run, and review XML metadata using Video XML QC v2.3.1. It is designed for media‑preservation environments where XML sidecar files accompany digitized video assets.
1. Prepare Your XML Files

Before running the program:

    Gather the XML files generated by your ingest or transcoding system.

    Ensure each XML file is complete and not partially written by another process.

    Place all XMLs you want to check into a single folder for easy batch processing.

This keeps the workflow predictable and avoids partial‑file errors.
2. Launch the Application

Run the executable:

    Double‑click Video XML QC v2.3.1.exe

    The program will open a console‑style interface

    You will be prompted to select the folder containing your XML files

The tool is designed for simplicity: no installation, no configuration files, no external dependencies.
3. Select the Input Directory

When prompted:

    Navigate to the folder containing your XML files

    Confirm your selection

    The program will automatically scan all XMLs in that directory

The tool supports batch processing, so you can validate dozens or hundreds of XMLs in one run.
4. Automated XML Validation

Once the directory is selected, the program performs:

    Schema checks  
    Ensures required fields and structures are present.

    Structural integrity checks  
    Detects malformed tags, broken hierarchies, and missing closing elements.

    Metadata consistency checks  
    Flags unexpected values, empty fields, or mismatched metadata.

    Error classification  
    Separates structural XML errors from ingest‑related anomalies.

This is the core of the QC process.
5. Review the QC Output

After processing, the program generates:

    A QC summary for each XML

    A pass/fail result

    A list of warnings, errors, and critical issues

    A consolidated report file (if multiple XMLs were processed)

Reports are formatted for readability and downstream review.
6. Address Any Issues Found

Depending on the results:

    Correct malformed XML structures

    Regenerate XMLs from the ingest system if needed

    Update metadata fields that fail validation

    Re‑run the QC tool to confirm the fixes

This ensures metadata integrity before files enter long‑term storage or downstream workflows.
7. Archive or Deliver the QC Results

Once all XMLs pass QC:

    Save the QC reports alongside the XMLs

    Deliver them to your preservation system, MAM, or QC team

    Optionally include the QC output in your project documentation

This completes the workflow.
